# Security Policy

## Scope

This policy covers the coursework notebooks and supporting files on the `main` branch.

## Report a vulnerability

Open the repository’s GitHub Security Advisories page and select **Report a vulnerability** to submit a private report. [GitHub Security Advisories](https://github.com/robertishimurasousa/Udacity-Beginner-Python-Certification-Prep/security/advisories)

Include the affected file and commit, your environment and relevant package versions, steps to reproduce the issue, and the potential impact. Redact credentials and personal data from all examples and attachments. Keep vulnerability details in the private report during triage.

Use GitHub Issues for ordinary coursework or documentation problems. For vulnerabilities in a third-party package or service, use that provider’s security reporting channel.
